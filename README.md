# Schlossknacker

Eine eigenständige Browser-App zum Lösen des Plattenrätsels.

## Start

`index.html` per Doppelklick in einem aktuellen Browser öffnen. Es werden keine
Installation, kein Server und keine Internetverbindung benötigt.

## Bedienung

1. Anzahl der Platten und Löcher einstellen.
2. Für jede Platte die Startposition wählen.
3. Rechts festlegen, welche anderen Platten sich gleich oder entgegengesetzt mitbewegen.
4. **Lösung berechnen** wählen.

Die Anwendung verwendet wie das ursprüngliche Python-Skript eine Breitensuche
und findet damit die kürzeste Lösung.
